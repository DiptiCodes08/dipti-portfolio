# Image Structure

Replace the files in each folder with your actual work.
All images are referenced from the portfolio automatically once placed here.

## Profile Photo
`/profile/`
- `photo.jpg` — Your headshot (used in Hero + About sections)
  - Recommended: 600×600px minimum, square crop, JPG or WebP

## MediQ Project
`/mediq/`
- `cover.png` — Main project card thumbnail (referenced in WorkSection)
  - Recommended: 1200×800px, shows the key screen or overview

## HomeEase Project
`/homeease/`
- `cover.png` — Main project card thumbnail
  - Recommended: 1200×800px

## Herald Sync Project
`/herald-sync/`
- `cover.png` — Main project card thumbnail
  - Recommended: 1200×800px

## DevOps Pioneer Community Work
`/devops-pioneer/`
- `poster-1.png` — Event poster design
- `poster-2.png` — Event poster design
- `banner-1.png` — Flex/roll-up banner design
- `banner-2.png` — Flex/roll-up banner design

## How to swap images in code
Once you add a real image, the Next.js <Image> component will use it automatically.
No code changes needed — just match the exact filename listed above.

If a file is missing, the coloured placeholder continues to show in its place.
